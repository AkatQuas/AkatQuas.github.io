制作可便携绿色 Python 3（Win7 x64）

May 16, 2026 · 2 min read

给 Win7 x64 打一份可整目录拷贝的绿色 Python，并补上 WingsApp Agent 需要的 python3 / pip3 入口。

一、准备官方 embed 包​

  1. 下载 Python 3.8.10 embeddable-amd64。
  2. 解压到无中文、无空格路径，例如 D:\Python3810。
  3. 编辑 python38._pth，去掉 #import site 前的 # 并保存。

二、安装 pip（清华源）​

保存 get-pip.py（3.8） 到 Python 根目录，在该目录执行：

python get-pip.py -i https://pypi.tuna.tsinghua.edu.cn/simple
.\python.exe -m pip config --site set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
.\python.exe -m pip config --site set global.trusted-host pypi.tuna.tsinghua.edu.cn

需要的库照常 python -m pip install ...；可用 pip freeze > requirements.txt 备份。

三、python3 / pip3 shim（WingsApp Agent 必做）​

官方 embed 只有 python.exe。在同目录新建：

python3.bat

@echo off
"%~dp0python.exe" %*

pip3.bat

@echo off
"%~dp0python.exe" -m pip %*

验收：python / python3 / pip / pip3 的 --version 都成功；若有 Git Bash，再跑 bash -c "python3 --version"。

四、打包与同事机使用​

整文件夹复制即可，路径仍须无中文无空格。可选把根目录和 Scripts 加进 PATH。

五、打进 WingsApp 桌面安装包​

桌面端由运行时助手管理内嵌 Python。运维把整目录（含 python.exe、shim、Scripts/、已装依赖）放进安装包：

用途路径
安装包内嵌<exe 所在目录>/python/versions/<版本目录名>/
用户运行时副本%AppData% 下应用数据目录的同结构（首次从 bundled 复制）

<版本目录名> 如 3.8、3.10，须有 python.exe。启动时会把 runtime 与 Scripts/ prepend 进子进程 PATH。

发版验收：安装目录下 python.exe 与 python3.bat 存在；CMD / Git Bash 能跑 python3；Agent 不应再报 python3: command not found。

Win10+ 可用 3.10+ embed；Win7 仍用 3.8.10。
