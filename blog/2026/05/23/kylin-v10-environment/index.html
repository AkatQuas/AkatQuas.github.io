银河麒麟 V10 环境备忘：绿色 Python 与源码编译 GCC

May 23, 2026 · 3 min read

在银河麒麟 V10（juniper / SP1 桌面版）上，经常要自备一份可移植的 Python，以及官方源没有的 GCC 9/10。两件事都记在这里。

一、Python 3.8.10 绿色移植（SP1 桌面版）​

前提​

  • 源机 / 目标机同为银河麒麟 V10 SP1（Debian 系），CPU 架构一致（同 x86_64 或同 ARM64）。
  • 系统自带 GCC 9.3 通常够用，编译 Python 不必先升 GCC。
  • 路径必须完全一致（例：~/.local/lib/python3810）。

源机器编译​

sudo apt update
sudo apt install -y gcc g++ make zlib1g-dev libbz2-dev libssl-dev \
  libncurses5-dev libsqlite3-dev libreadline-dev tk-dev libgdbm-dev \
  libdb-dev libpcap-dev xz-utils libffi-dev

mkdir -p ~/.local/lib/python3810
cd /tmp
wget https://www.python.org/ftp/python/3.8.10/Python-3.8.10.tgz
tar -zxf Python-3.8.10.tgz && cd Python-3.8.10

./configure --prefix=$HOME/.local/lib/python3810 \
  --enable-static --disable-shared --with-ensurepip=yes
make -j4
make install

~/.local/lib/python3810/bin/python3.8 --version

装业务依赖后打包：

~/.local/lib/python3810/bin/pip3.8 install requests flask numpy pandas
cd ~/.local/lib && tar -zcvf python3810_green.tar.gz python3810/

目标机器​

解压到相同路径，再把 bin 写进 PATH：

cd ~/.local/lib && tar -zxvf python3810_green.tar.gz
echo 'export PATH=~/.local/lib/python3810/bin:$PATH' >> ~/.bashrc
source ~/.bashrc

避坑：路径必须一致；必须静态编译（--enable-static），否则缺系统库；不要混用系统 Python。

二、源码编译 GCC 9 / GCC 10​

适用：官方源没有目标 GCC 版本时，指定 --prefix 安装，不污染系统默认编译器。

通用依赖​

sudo apt update
sudo apt install -y build-essential wget bzip2 \
  libgmp-dev libmpfr-dev libmpc-dev texinfo libisl-dev

GCC 9.5.0（GCC 10.5.0 同理改版本号与 prefix）​

cd /usr/local/src
sudo wget https://mirrors.tuna.tsinghua.edu.cn/gnu/gcc/gcc-9.5.0/gcc-9.5.0.tar.xz
sudo tar -xf gcc-9.5.0.tar.xz && cd gcc-9.5.0
sudo ./contrib/download_prerequisites
sudo mkdir build && cd build

sudo ../configure \
  --prefix=/usr/local/gcc-9.5.0 \
  --enable-languages=c,c++ \
  --disable-multilib \
  --disable-bootstrap

sudo make -j$(nproc)
sudo make install

echo 'export PATH=/usr/local/gcc-9.5.0/bin:$PATH' >> ~/.bashrc
echo 'export LD_LIBRARY_PATH=/usr/local/gcc-9.5.0/lib64:$LD_LIBRARY_PATH' >> ~/.bashrc
source ~/.bashrc

GCC 10：把 9.5.0 换成 10.5.0、prefix 换成 /usr/local/gcc-10.5.0 即可。两版可共存。

临时切换不必改默认：

export CC=/usr/local/gcc-9.5.0/bin/gcc
export CXX=/usr/local/gcc-9.5.0/bin/g++

说明：--disable-multilib 只编 64 位；--enable-languages=c,c++ 加快编译；整机编译大约 10–40 分钟。
